L'objective c'est de mettre en place une communication client/serveur.
Le client envoie une chaîne de caractères représentant une opération mathématique (ex : 5 + 3),
et le serveur effectue le calcul puis renvoie le résultat au client.
Structure du projet:
src/
 ├── serverPackage/
 │     └── Server.java
 └── clientPackage/
       └── Client.java
